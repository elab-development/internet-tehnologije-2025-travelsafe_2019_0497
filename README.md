# TravelSafe

Fullstack web aplikacija za onlajn izdavanje putnog osiguranja.

Projekat iz predmeta Internet tehnologije, Fakultet organizacionih nauka.

## Planirana arhitektura

- **backend/** — REST API u Laravel okviru (PHP, MySQL)
- **frontend/** — jednostranicna aplikacija u React-u

## Uloge nad sistemom

- **CLIENT** — unosi putovanja i putnike, podnosi zahtev za polisu
- **AGENT** — odobrava ili odbija pristigle zahteve
- **ADMIN** — upravlja korisnicima, paketima i prati statistiku
